# Линия креативов

Настольное приложение для Windows: из ссылок на видео и записей стримов делает готовые вертикальные ролики (9:16) для
TikTok / Reels / Shorts. Сделано под личную работу, передаётся как **рабочий прототип**: важнее идея и то, как она реализована,
чем отполированность кода. Код будут проверять и улучшать — ниже честно написано, где слабые места.

## Идея

Линия: найти и скачать → вырезать нужное → оформить → проверить → выгрузить. Каждое ручное действие либо автоматизировано,
либо сводится к клику. Четыре принципа, на которых всё построено:

1. **Автоматика собирает черновик целиком, человек только правит и одобряет.** Ролик собирается сам, правки — мелкие.
2. **Правки не пересобирают всё.** Предпросмотр живой (браузерный JS, мгновенный), финальный файл собирает ffmpeg по кнопке
   (~20 секунд на ролик 20 секунд).
3. **Каждая функция = кнопка + команда `app_cli.py` + строка в `tools/shared_bot/app-AGENTS.md`.** Приложением может управлять
   ИИ-ассистент по HTTP API так же, как человек кнопками (окно при этом — «витрина»).
4. **Ядро не зависит от Telegram.** Первой версией был Telegram-бот; вся логика вынесена в `core.py`, приложение работает без
   Telegram. Самого бота в этом репозитории нет.

## Экраны

| Экран | Что делает |
|---|---|
| Загрузки | Ссылка + обрезка («`1:20-1:45`», «`до 58`», «`-5 -3`») → клип. С подписью — сразу креатив 9:16 с жёлтой плашкой |
| Выбор клипов | Запись стрима Kick/Twitch → 10 моментов (по клипам зрителей) с превью → «Взять» |
| Отобранные | Что взято в «Выборе клипов»; кнопка прогона через Edits |
| Нарезка | Исходник-подборка с несколькими моментами → автоматика находит смены сцены, названия (Windows OCR / Whisper), рамку, рекламные вставки → редактор → куски |
| Топ 3/5 | Из чистых клипов одного стримера собирает ролики «топ-3 / топ-5» так, чтобы два ролика не повторяли больше N общих моментов |
| **Саша (❤️)** | Главный экран. Видео по ссылке с таймкодами «от-до» → кадр 9:16 по лицу + цветокор + пословные субтитры + музыка. Собирается сам, правки в одном окне (см. ниже) |
| Очередь Edits | Прогон готовых роликов через Instagram Edits на iPhone по кабелю (WebDriverAgent) — часть про «настоящий» экспорт |

## Как устроено

```
tools/shared_bot/
  app.py            NiceGUI-приложение: экраны, HTTP API (/api/…), состояние
  core.py           логика без интерфейса: разбор ссылки и обрезки, скачивание (yt-dlp + ffmpeg),
                    моменты Kick/Twitch, креатив с плашкой, запуск прогона Edits
  sasha.py          очередь экрана «Саша»: скачать с запасом ±3 с → Whisper → авто-сборка → правки
  split.py, tops.py «Нарезка» и «Топ 3/5»
  sasha_preview.js  браузерный предпросмотр «Саши»: кадр, субтитры, таймлиния, дорожка музыки
  split_editor.js   редактор «Нарезки»
  app_cli.py        те же действия из командной строки/для ИИ; app-AGENTS.md — их описание
tools/subs/
  make.py           сборка ролика одним графом ffmpeg
  subs.py           субтитры в формате ASS: «лесенка» из первых слов + дальше по одному слову
  fixtext.py        правка текста с сохранением таймингов слов
  config.json, styles.json, filters.json   числа, стили субтитров (шрифты), фильтры ролика
tools/wda/          айфон-часть (Edits)
tools/kick_clips.py, twitch_clips.py       моменты стримов
```

**Сборка ролика («Саша»).** `make.py` делает один ffmpeg-граф: поиск лица (YuNet, OpenCV) → одно **неподвижное** окно кадра на
весь ролик (камера не двигается) → размытая копия кадра фоном сверху и снизу → фильтр (цветокор из `filters.json`, интенсивность
0–100 %) → маска виньетки → субтитры ASS → музыка (громкость по LUFS относительно голоса, сдвиг, ползунок громкости). Слова —
из Faster-Whisper, текст перед сборкой правится вручную (тайминги слов сохраняются, `fixtext.py`).

**Предпросмотр.** `sasha_preview.js` повторяет геометрию кадра и субтитры теми же формулами, что `make.py`/`subs.py`
(это важно: расхождение сразу видно глазами). Живёт в браузере: зум, границы куска (красные линии на таймлинии), музыка с
волной и сдвигом, субтитры двигаются и масштабируются прямо на кадре (рамка с углами и поворотом), шрифт/цвет/обводка/сияние/
непрозрачность по каждому слову лесенки и по блоку «остальные слова». Правки уходят на сервер событиями и сохраняются сразу.

**Решения, которые стоит знать:**
- *Размер шрифта в ASS* — это высота строки, а не буквы; в браузере нужен коэффициент (`em_ratio` в `sasha.py`), иначе предпросмотр
  рисует текст в ~1.4 раза крупнее ролика.
- *«Есть правки без пересборки»* определяется сравнением отпечатка настроек (`_sig`/`rsig` в `sasha.py`) с тем, что было при последней
  сборке. Одобрить кусок с неотражёнными правками нельзя.
- *Стиль по умолчанию + одобрение:* вид (субтитры, стиль, музыка, фильтр) запоминается кнопкой ★ и применяется к новым кускам; одобренные
  копии складываются в отдельную папку.
- *Прерванная работа продолжается сама* после перезапуска приложения (`Sasha._resume`, не больше двух раз подряд).
- *Скорость сборки* (сборка ролика 20 с: 101 с → ~20 с): `fps=30` в начале графа, размытие фона на ¼ размера, тонмап только для HDR,
  кэш найденного лица, готовая маска виньетки вместо фильтра, `blend=multiply` вместо наложения прозрачной картинки.
- *Запись состояния* (`app_state.json`) повторяется при `PermissionError` — на Windows файл иногда занят.

## Установка (только Windows 10/11)

1. Python 3.10+, `pip install -r requirements.txt`.
2. Положить `Faster-Whisper-XXL` в `tools/fw/Faster-Whisper-XXL/` (нужны `faster-whisper-xxl.exe`, папка `_models` с `large-v3` и **`ffmpeg.exe`** —
   приложение берёт ffmpeg оттуда, путь задан в `core.py`).
3. `yt-dlp.exe` положить в `tools/shared_bot/bin/`.
4. Модель лица YuNet → `tools/subs/models/` (см. README там).
5. По желанию шрифты стилей → `tools/subs/fonts/` (см. README там). Без них доступны только стили на Arial Black.
6. Запуск: `tools\shared_bot\app.bat` (окно) или `python tools/shared_bot/app.py --browser` (в браузере, `http://127.0.0.1:8765`).

При первом запуске рядом с `app.py` создаётся `config.json` (папка готовых клипов `out_dir`, временная `tmp_dir`, лимиты). Все данные приложения
(состояние, превью, рабочие файлы, библиотека музыки `music/`) лежат в `tools/shared_bot/` и в репозиторий не попадают (`.gitignore`).

Управление из командной строки / ИИ: `python tools/shared_bot/app_cli.py` — список команд в шапке файла и в `app-AGENTS.md`.

## Чего нет в репозитории (намеренно)

Секреты (токены, сессии Telegram, ключи), шрифты, бинарники (ffmpeg, yt-dlp, Whisper, `.ipa` WebDriverAgent), личные данные и
рабочие файлы, Telegram-бот. Перед публикацией код просмотрен на токены и личные пути; в `core.py` значения по умолчанию безличные.

## Известные недоработки

**Слабое место кода.** `app.py` — монолит на ~2700 строк (интерфейс, API и состояние вместе); автотестов нет; состояние одним JSON-файлом;
пути к ffmpeg/Whisper зашиты в `core.py`; много «магических» чисел в `config.json`; только Windows (`msvcrt`, Windows OCR, `pythonw`).

**«Саша (❤️)»:**
- Цветное слово в лесенке выбирается вручную (кликом) или стилем по умолчанию — **по номеру слова**, а не по смыслу. Варианты автоматики:
  самое длинное слово без служебных; фиксированный номер; по очереди; выбор ИИ — решение не принято.
- Фильтр «Старый Голливуд» — приближение «на глаз» к фильтру CapCut; предпросмотр цвета и шрифта приблизителен, точный результат — в сборке.
- Кадр — одно неподвижное окно (лицо не отслеживается во времени); без найденного лица ролик не собирается.
- Whisper и сборка идут по одному (видеокарта 6 ГБ), порядок кусков в очереди не гарантирован.

**«Нарезка» / «Топ 3/5»:** списки, наложенные поверх видео, OCR не читает; короткие названия вида «1 vs 1» теряют символы; составной кадр
«две камеры + игра» проверен не на всех источниках; раздельные куски одного момента без рекламы между ними не склеиваются.

**Айфон-часть:** нужен iPhone, кабель и подпись WebDriverAgent своим Apple ID (раз в 7 дней); русский и английский iOS; нестандартные окна —
вопрос уходит человеку (в приложении карточкой).
