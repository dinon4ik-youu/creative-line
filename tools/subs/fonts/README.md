# Шрифты стилей субтитров

Файлы шрифтов в репозиторий не входят (лицензии). Положи сюда `.ttf` / `.otf`, имена — как в `../styles.json` (поле `font_file`). Стиль, для которого файла нет, в приложении просто не показывается.

Использовались: Dudu Cyrillic, Gogol, Leonov, Liana, Pushkin, Rimma Sans, SC Jurerê, Sweet Mavka; базовый — Arial Black (системный, `C:/Windows/Fonts/ariblk.ttf`). Семейство шрифта в `styles.json` (`font`) должно совпадать с именем семейства **внутри файла** (оно может отличаться от имени файла — например, у Rimma Sans для Windows это «Rimma_sans Bold»); проверять рендером.
