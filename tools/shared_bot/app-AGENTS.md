# «Линия креативов» — инструкция для ИИ

Ты помогаешь человеку делать короткие вертикальные креативы. У него есть настольное приложение «Линия креативов»:
кнопки для тех, кто работает руками. **Ты управляешь тем же приложением из терминала — через `app_cli.py`**,
кнопки в окне не нажимай. Всё, что ты делаешь командами, сразу видно в окне: человек смотрит туда как на витрину.

Запуск: `python app_cli.py <команда>` из папки с `app.py`. Приложение не запущено — `app_cli` запустит его сам
(окно стартует ~20 с). `--json` у любой команды — ответ целиком, удобно разбирать.

## Что умеет

| Человек просит | Команда |
|---|---|
| «что там сейчас?» | `status` |
| скачать видео (Kick, Twitch, TikTok, YouTube, Instagram…) | `download URL [URL…] --wait` |
| скачать кусок | `download "URL -5 -3" --wait` (первые 5 с и последние 3 с прочь) · `"URL до 58"` · `"URL 1:20:00-1:20:10"` |
| сделать креатив 9:16 с подписью | `download "URL" --caption "текст плашки" --wait` |
| что уже скачано | `list` (`--all` — всё) |
| отменить / убрать / перекачать | `cancel ID` · `remove ID` · `retry ID` |
| моменты из записи стрима | `pick URL` → `moments` (`--more` — ещё 10) |
| взять момент | `take N [--long] [--cut "-1 -5"] [--caption "…"] --wait` · в папку топ-3/5 (без подписи): `take N --pool Стример --wait` |
| прогнать через Edits на айфоне | `edits ID [ID…]` (только готовые вертикальные) |
| куда класть готовое после Edits | `mode phone` (только галерея айфона) · `mode pc` (вернуть на ноутбук: `<имя>_edits.mp4` рядом) |
| пачка Edits застряла / порядок | `job retry JOB` · `job cancel JOB` (только ждущую) · `job stop JOB` (идущую на айфоне) · `job remove JOB` (убрать неидущую карточку из списка) · готовое после Edits в режиме «на ноутбук» — `<out_dir>\готово-edits\` · `edits-start` (начать прогон файлов, загруженных кнопкой «Загрузить с компьютера») · `job up JOB` · `job down JOB` |
| подборки топ-3 / топ-5 (экран «Топ 3/5») | `tops add-folder СТРИМЕР ПАПКА` · `tops add СТРИМЕР ФАЙЛ` → `tops set --k 3 [--level strong|medium|weak | --shared N] --title "ТОП 3 МОМЕНТА ЕВЕЛИНОВ"` → `tops build [--count N] --wait` |
| исходник с несколькими моментами → куски для топ-3/5 (экран «Нарезка») | `split open "URL1 -5 -3" "URL2" … --pool Стример --wait` (очередь; ссылки можно слитно) → `split` (что нашла автоматика) → при нужде `split set --segs '[…]'` → `split send --wait` |
| видео → 9:16 + холодный цветокор + пословные субтитры + музыка (экран «Саша (❤️)») | `sasha add "ССЫЛКА 1:20-1:45 2:00-2:30" --wait` (каждый отрезок от-до — свой кусок; качается С ЗАПАСОМ ±3 с, можно и путь к файлу). **Ролик собирается сам целиком** (Whisper → сборка, зум ×1) → `sasha` (статус, путь, текст, границы, зум, музыка, библиотека треков) → мелкие правки: **прочитай текст, исправь ошибки Whisper** — `sasha text ID "весь исправленный текст"` (слова без знаков, тайминги сохранятся; правится только слова внутри границ), `sasha zoom ID 1.3` (×1 автокадр по лицу, больше — крупнее, меньше — отдалить, по бокам размытие), `sasha trim ID 1:08.5 1:26` (границы в времени ИСХОДНОГО видео, в пределах «доступно» из вывода `sasha`), `sasha track ПУТЬ` (трек в библиотеку), `sasha music ID ИМЯ|none` (музыка куска) → `sasha render ID --wait` (пересборка) → `<out_dir>\Саша\<имя>_sasha.mp4`. `sasha style ID "Только по слову"` (стиль субтитров; стили — `tools/subs/styles.json`, новый стиль = новая запись «имя → что поменять поверх config.json»; шрифт-стиль = `{"font": семейство, "font_file": абсолютный путь}`, файлы лежат в `tools/subs/fonts/` (имена файлов — ASCII!), семейство берётся из таблицы name шрифта — для Windows-файлов может отличаться от PIL, проверять рендером с `fontsdir`). `sasha adj ID '{"ladder":[{"dx":-80,"s":1.2}],"single":{"dy":-150}}'` (настройки субтитров: слова лесенки — каждое своё, все слова после лесенки — один блок; поля dx/dy — сдвиг в px холста 1080×1920, s — масштаб, r — поворот в градусах, font — семейство шрифта (список — `sasha` → fonts в API), color — #RRGGBB, b/i/u — жирный/курсив/подчёркнутый; в окне это панель под кадром: выделяешь слово кликом, правой кнопкой или двумя пальцами на тачпаде, тянешь рамку). `sasha moff ID 12.5` (сдвиг музыки в секундах: >0 — в начале ролика играет эта секунда трека, <0 — музыка стартует позже; в окне это дорожка музыки под таймлинией, её тянут мышкой). `sasha defaults save ID` (запомнить вид куска — субтитры, стиль, музыка — для ВСЕХ новых кусков) · `sasha defaults apply` (на все непроверенные; пересборка по очереди) · `sasha approve ID [--undo]` (одобрить готовый кусок после проверки; копия уходит в `<out_dir>\Саша\одобрено\`; нельзя, пока в файл не вошли правки — сначала `render`). Порядок с человеком: он правит первый кусок → «запомнить как по умолчанию» → остальные проверяет и одобряет. `sasha filter ID "Старый Голливуд" 70` (фильтр ролика и интенсивность 0–100; «Холодный» — прежний цветокор; «Старый Голливуд» — моё приближение: приглушённый цвет, сепия, контраст, зерно, виньетка; список — `tools/subs/filters.json`). `sasha mvol ID 80` (громкость музыки, %: 100 — на 8 дБ тише голоса, 0 — тишина, до 200; сдвиг и громкость музыки входят в стиль по умолчанию). `sasha reset ID` — текст как расшифровал Whisper. В окне то же в одном экране: слева живой предпросмотр (субтитры, цвет, зум, музыка по 🔊) и вкладка «Готовый ролик», справа текст, зум, границы, музыка |
| поправить название / убрать клип подборки | `tops rename СТРИМЕР N "название"` · `tops remove СТРИМЕР N` (файл остаётся) |
| айфон что-то спрашивает | `question` → `answer …` |

ID загрузки — число `#N` из вывода `download` / `list`. JOB — id пачки из `status --json` → `edits.jobs[].id`.

## Топ 3/5 (подборки)
Клипы в подборке должны быть уже чистые (без чужих надписей и рекламы) — приложение их не чистит. Название клипа
по умолчанию — имя файла; перед сборкой проверь, что названия короткие и читаемые (они печатаются в списке на плашке).
`tops build` сам считает, сколько роликов выйдет (топ-3: любые два ролика делят ≤1 момент, топ-5: ≤2), собирает
в `<out_dir>\подборки\<стример>_топ<k>_<дата>\` и пишет `список.txt`. До 24 клипов в подборке.
Скачать сразу в подборку: `download "URL" --pool Стример --wait` — клип копируется в `<out_dir>\топ-клипы\Стример\` и попадает в подборку.
Нарезка: рекламные баннеры автоматика вырезает сама (куски с `ad: true`, помечены «не брать»): по стоп-кадру под
анимированным прямоугольником и по цветной рамке из `banner_refs.json` (по умолчанию жёлтая рамка Upgrader; новый
баннер с другой рамкой — добавить строку `{"name": …, "hsv": [от, до, насыщ., яркость]}`). Хвосты рекламы бывают — проверь края.
Автоматика сама предлагает названия по сказанному (`said` — расшифровка речи куска, `name` — первая фраза), но реплика ≠ хорошее
название: прочитай `said` и дай короткое название (2–4 слова, как у человека в списке «ТОП 3»). **Проверка черновика: `split sheet`**
— одна картинка с кадрами, кусками, рамками и рекламой; посмотри её, потом правь `split set` и только потом `split send`.
Моменты в подборках «ТОП N» автоматика разделяет по появлению новых названий в списке на экране (список только растёт: новая строка = новый момент) и по смене сцены; название куска = эта строка (`title_start: true`, `name_src`: «экран»). Метки лежат в поле `marks`. Если на экране списка нет — остаются разрезы по сцене и названия по речи.
Горячие клавиши в окне редактора (для людей, не для ИИ): Пробел — пуск/пауза, ← → — кадр (Shift — секунда), Q (Й) — разрезать, E (У) — склеить со следующим, Del — не брать.
Автоматика сама читает список названий с экрана (встроенное распознавание текста Windows, язык «ru») и ставит их как `name` (`name_src`: «экран» или «речь»); украинские «і», «щ» движок иногда путает — проверяй по сводке. Куски до и после вырезанной рекламы из одной сцены она склеивает сама (`join: true` у второго куска → при `split send` один клип).
**Настоящие названия обычно написаны на экране**: в подборках-«топах» вверху кадра список («1. Легендарна, 2. Постукав…»), и строка появляется, когда показывают момент. Прочитай их на `split sheet` и называй куски так, а не по `said` (по речи названия выходят приблизительные). Если реклама стоит посреди одного момента, куски до и после неё — один момент: объедини их в одно название или оставь как есть и скажи человеку.
Автоматика режет по сменам сцены и ставит рамку (без размытого фона), но ошибается примерно в половине
кусков. Если человек работает в окне — пусть правит рамки и разрезы там и жмёт «Отправить» сам. Если правишь ты —
посмотри кадры (умеешь картинки — вытащи кадр ffmpeg'ом) и задай `crop` [x, y, w, h], `skip` для рекламы, `name`.
**Уникальность подборки (27.10.2026):** `--level strong|medium|weak` (сильная / средняя / слабая) или `--shared N` — сколько общих моментов
может быть у двух роликов. Топ-3: 0 / 1 / 2, топ-5: 1 / 2 / 3. Чем меньше, тем меньше роликов выйдет, но они меньше похожи. Без выбора — средняя.

**Падеж стримера в заголовке сам не выбирай и не склоняй:** `tops set --tail "ЕВЕЛИНОВ"` — хвост вводит человек
(получится «ТОП 3 МОМЕНТА ЕВЕЛИНОВ»); не знаешь, как писать, — спроси.

## Обрезка
Пишется после ссылки через пробел, ссылку с обрезкой — в кавычки:
`-14` — убрать первые 14 с · `-5 -3` — 5 с в начале и 3 с в конце · `до 58` — только до 58-й секунды ·
`1:20-1:45`, `1:20:00-1:20:10` — кусок записи. Для `take` то же, но в `--cut`, без ссылки.

## Выбор клипов (стрим)
`pick` принимает запись Kick/Twitch (`kick.com/<канал>/videos/…`, `twitch.tv/videos/…`) или канал (последний стрим).
Ссылка с `?t=` — моменты только с этого места. `moments` выводит моменты по убыванию «сколько раз заклипали»:
время панча, длина короткого клипа (панч в первые секунды) и длинного (с предысторией), путь к превью 360p
(можно посмотреть, если умеешь видео/кадры). Человек обычно говорит «возьми 1, 3 и 5» или «третий длинный, -2 -4».

## Вопросы айфона
Прогон Edits на айфоне иногда застревает на незнакомом окне и спрашивает. `status` и `question` это показывают:
текст, варианты-надписи с номерами, путь к скрину (`pic`). Посмотри скрин (если умеешь картинки) и ответь:
- `answer N` — нажать надпись N (запомнится, в следующий раз нажмёт сам);
- `answer "клик 0.52 0.71"` — нажать в точку (доли ширины и высоты экрана), если нужной надписи нет в списке;
- `answer повтори` — человек сам поправил на телефоне, повторить шаг;
- `answer стоп` — остановить прогон. **Стоп — только если человек сам сказал.**

Не уверен, что нажать, — покажи человеку скрин и варианты и спроси. Неверное нажатие запоминается.

## Правила
- Готовое — в папке из `status --json` → поле `file` у загрузки. Исходники и готовые файлы человека не удаляй.
- Долгие дела (`--wait` у скачивания, Edits ~1 мин на ролик) — скажи человеку, что ждёшь, и чем закончилось.
- Ошибка (`❌ …`, код выхода 1) — перескажи человеку своими словами и предложи, что делать.
- В Edits идут только вертикальные 9:16. Горизонтальное сначала сделать креативом (`--caption`).
