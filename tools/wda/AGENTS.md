# Контекст для ИИ-помощника: прогон креативов через Instagram Edits на iPhone

Этот файл — для ИИ (Claude Code, Gemini CLI, ChatGPT / Codex и т.п.), которому человек открыл эту папку и попросил
«почини / настрой под мой телефон». Отвечай человеку на его языке, по шагам, без воды.

## Что делает линия
`edits_iphone.py <серия или папка>` берёт готовые mp4 и прогоняет каждый через настоящее приложение
Instagram Edits на iPhone, подключённом к Windows-ноутбуку по кабелю, чтобы получить настоящий айфонный
экспорт (HEVC 1440×2560, 60 fps, подпись `com.burbn.basel`):
1. Делает лёгкие копии 1080p с датой съёмки «завтра 00:00 + n минут». По этой подписи («19 октября, 00:03»)
   скрипт находит каждый исходник в «Фото» и в выборе Edits.
2. Шлёт их в Telegram-бота (`tools/tg.py`, токен в `tools/tg-config.json`). На телефоне: чат с ботом →
   выделить файлы → Share → «Сохранить N видео».
3. Edits: + → Галерея → видео → 2K / 60 → Далее → «Скачать».
4. Уборка: проекты Edits в корзину, исходники из «Фото» удалить; экспорт забирается по кабелю (AFC).

Управление телефоном — WebDriverAgent (WDA) по адресу http://127.0.0.1:8100. Поднимает связь `start.py`
(туннель pymobiledevice3 с правами администратора, монтирование образа разработчика, запуск WDA, проброс порта).

## Как устроена устойчивость (сначала смотри сюда)
- Каждый шаг идёт через `guard()`. Обрыв связи → `start.py` заново. Незнакомое окно → человеку в бота
  уходит скрин и список кнопок, он отвечает номером, ответ сохраняется в `auto-taps.json`
  («окно с таким текстом → жми эту кнопку»).
- Своя кнопка скрипта не нашлась (`Missing`) → вопрос «где тут X?» со списком надписей на экране.
  Ответ сохраняется в `aliases.json` («условие поиска → настоящая надпись на этом телефоне»), цифры
  заменяются на `#`, поэтому «Сохранить 7 видео» и «Сохранить 3 видео» — одна запись. Поиск через `Phone.find()`.
- Координаты сняты на iPhone 11 (`BASE_W, BASE_H = 414, 896` точек). `Phone.at()` пересчитывает их под
  размер экрана, масштаб снимка = ширина снимка / ширина экрана в точках.

## Частые поломки и что делать
| Симптом | Причина | Что сделать |
|---|---|---|
| `http://127.0.0.1:8100/status` не отвечает | связь не поднята, телефон заблокирован | разблокировать, `python -u start.py` |
| WDA не запускается, «не доверенный разработчик» / истёк профиль | подпись бесплатного Apple ID живёт 7 дней | переподписать `WebDriverAgent.ipa` в Sideloadly тем же Apple ID |
| «в галерее нет видео с подписью …» | iPhone не на русском → подпись даты другая | поменять `MONTHS` и формат в `Item.caption` под язык телефона (сверить с `wda.py tree` в «Фото») |
| Скрипт спрашивает одну и ту же кнопку снова и снова | надпись с меняющейся частью, не цифрой | посмотреть `aliases.json`, обобщить условие в коде (`BEGINSWITH` / `CONTAINS`) |
| Жмёт мимо на другой модели | точка, которую нельзя пересчитать пропорцией | `wda.py tree имя` → найти элемент по `name` / `label` и искать его, а не жать в точку |
| Телеграм-бот не отвечает на вопросы | чужой процесс читает getUpdates этого токена | у бота должен быть один читатель — `tg.py` |

## Разведка экрана
- `python wda.py shot имя` — снимок в `shots/имя.png`.
- `python wda.py tree имя` — все элементы с `name` / `label` / `rect` в `shots/имя.xml`.
- `python explore.py имя` — список кнопок экрана.
- `python wda.py tap X Y` — нажатие в пикселях снимка (масштаб считается сам).

## Правила
- Не выдавать Edits полный доступ к «Фото» — экспорт работает с частным доступом.
- Не удалять исходники из папки серии; оригиналы перед заменой кладутся в `backup/`.
- Не трогать `tg-config.json` и сессии Telegram — это секреты, никуда их не пересылать.
- Правку кода проверять на одном креативе: `python edits_iphone.py <папка> --only 1`.
